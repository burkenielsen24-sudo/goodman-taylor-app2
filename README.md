## 🏃 Running Locally

### Prerequisites

- Python 3.8 or higher
- pip package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/burkenielsen24-sudo/goodman-taylor-app2.git
cd goodman-taylor-app2
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
streamlit run streamlit_app.py
```

4. Open your browser and navigate to `http://localhost:8501`

## 📦 Deployment to Streamlit Cloud

1. Push your code to GitHub (this repository)
2. Go to [share.streamlit.io](https://share.streamlit.io/)
3. Sign in with your GitHub account
4. Click "New app"
5. Select this repository (`burkenielsen24-sudo/goodman-taylor-app2`)
6. Set the main file path to `streamlit_app.py`
7. Click "Deploy"
